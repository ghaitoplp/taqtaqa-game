# طقطقة — GitHub One ZIP

هذا الملف مخصص للطريقة التي سنستخدمها من الهاتف:
1. ارفع ملف `Taqtaqa_Phone_APK_Project.zip` إلى مستودع GitHub.
2. ارفع مجلد `.github/workflows` وملف `build-apk.yml` أيضًا.
3. شغّل GitHub Actions يدويًا.
4. نزّل Artifact باسم `Taqtaqa-APK`.
5. فك الضغط وثبّت `app-debug.apk`.

مهم: GitHub Actions يحتاج ملف workflow داخل `.github/workflows`.
